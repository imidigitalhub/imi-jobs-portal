# IMI Jobs & Opportunities Portal

A responsive opportunity-discovery portal by IMI DIGITAL HUB. The first frontend prototype includes category browsing, keyword search, location filtering, sorting, opportunity cards and a submission contact link.

## Current prototype status

- Static HTML, CSS and JavaScript.
- Example cards are explicitly marked **DEMO EXAMPLE**. They are not real vacancies, scholarships or verified listings.
- No live database, administrator authentication, user accounts, or automatic publishing yet.
- The submission link opens an email draft; it does not store submissions.
- Before launch, replace examples with verified opportunities and official source/application URLs.

## Run locally

Open `index.html` in a browser, or use a local static server.

## WordPress integration

The same static frontend can be embedded in a WordPress page after the standalone version is deployed. A later backend/API will be needed to share live listings and admin publishing between both versions.

## Planned next stages

1. Connect a secure database and authenticated admin dashboard.
2. Add opportunity create/edit/archive workflows and source verification fields.
3. Add official application links, deadlines, reminders and moderation.
4. Deploy to GitHub Pages.
5. Integrate the published portal into the IMI DIGITAL HUB WordPress site.
